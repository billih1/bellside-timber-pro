# BELLSIDE — Timber Pro

> Cinematic, luxury dark-mode 3D scroll experience launching BELLSIDE's flagship **Timber Pro** structural engineered beam.

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy)

## Overview

BELLSIDE Timber Pro is presented as a high-end luxury tech release (Apple-style keynotes) with 9 interactive and scroll-scrubbed chapters:

1. **Chapter 1: The Monolith (SPIN)** — Orthographic pseudo-3D rotating timber beam rendered on dynamic 2D canvas with smooth cross-fade into high-resolution Kling 3 Omni plate.
2. **Chapter 2: The Core (MILL)** — Interactive precision tolerance mill inspection with sawdust decay particle physics.
3. **Chapter 3: Deflection (LOAD)** — Real-time mechanical structural testing with quadratic bezier beam deflection under up to 5,000 kg load.
4. **Chapter 4: Microstructure (GRAIN)** — Procedural hash-noise (`noise2D`) cellular grain visualization.
5. **Chapter 5: Cellular Honeycomb (BUILD)** — Hexagonal cellular core animation highlighting strength-to-weight optimization.
6. **Chapter 6: 15-Year Weather Lens** — Interactive dual-canvas circular cursor lens revealing golden preserved timber beneath a 15-year weathered grey plate with live mouse telemetry.
7. **Chapter 7: Drag-to-Spin 3D Inspector** — Pointer-locked manual rotation and tilt inspector with dynamic specular reflections.
8. **Chapter 8: Product Lineup** — Full structural dimension variants (200x50mm to 400x100mm) with live specs.
9. **Chapter 9: Quote Request** — Custom dimension calculator and immediate trade pricing inquiry form.

## Technology Stack

- **Pure HTML5 / CSS3 / Vanilla JavaScript** (Zero build step, instant deployment)
- **HTML5 Canvas 2D/3D Procedural Shaders** (High-DPI retina rendering via `window.devicePixelRatio`)
- **Web Audio API Procedural Synthesizer** (Bandpass-filtered saw cutting noise and exponential structural creaking)
- **Kling 3 Omni High-Resolution WebP Plates** (`hero-beam.webp`, `weathered-beam.webp`)

## Deployment on Render

This project is configured with `render.yaml` for instant Render Static Site hosting:
1. Connect your GitHub repository to Render.
2. Select **Static Site** or **Blueprints**.
3. Set **Publish directory** to `.`.
